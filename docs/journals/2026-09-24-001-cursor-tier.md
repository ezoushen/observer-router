# 2026-09-24-001 — cursor tier before the local lane

## 02:10 — Composer measured on real observer prompts

- Outcome: six `bench_prompts.json` prompts (7.5k to 27.8k characters) through the bridge,
  non-streaming. `composer-2.5` answered in 14.4 to 26.6 s; five were well-formed
  `<observation>` XML and the smallest was an empty response, which is the skip that
  claude-mem's prompt asks for on routine tool calls. `composer-2.5-fast` was no faster on this
  shape (11.8 to 24.4 s), explained its skip in prose, and prefixed one answer with a stray
  token, so the tier defaults to `composer-2.5`.
- Outcome: at the time both free remote tiers were answering 429 on every call, so the local
  lane was serving all observer traffic.
- References: `ochre/report/evidence/2026-09-13-claude-mem-9b-vs-a3b/bench_prompts.json` in the
  parent workspace.

## 02:20 — tier added, opt-in

- Outcome: `cursor` tier with a 40 s budget, enabled on this machine through
  `OBSERVER_ROUTER_CHAIN=gemini,openrouter,cursor,local` in the installed plist. The default
  chain is unchanged because the bridge is a separate install. The four budgets sum to 152 s,
  over claude-mem's 120 s timeout; that only bites when every tier hangs to its budget.
- Open: an obeyed skip returns empty content, which the router counts as a failure, so the
  local lane runs next and may record what Composer skipped.
- References: `observer-router.py`, `test_observer_router.py`, `README.md`.
